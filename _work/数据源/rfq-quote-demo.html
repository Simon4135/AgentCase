12 项必需要素中，8 项齐全，4 项客户没写清。缺口不阻塞报价 —— 但会按口径假设继续算，并记下来留到最后统一算影响。

这一步的看点 · 不是「读表格」，是「判断能不能报」Agent 没有停下来问人，也没有假装图纸是完整的。它做的是第三种处理：先按最可能的口径往下算，同时把每一个假设记下来，留到最后一步统一算金额影响。

这正是老练报价员的做法 —— 缺项不等于停止报价，但绝不能默默按便宜口径报出去就算完。

这是这个 Demo 里最值得讲的一点：公司两年前在一单上亏掉的两千五，这次被 Agent 主动想起来了，不靠当年经手的老员工还在不在职。

反算校核

拿 91% 相似度那单的实际成本 951.20 起算，逐项修正到本次条件（钢价变动 / 展开面积增加 / 折弯增加 / 批量差异），再与本次独立算出的成本对比 —— 两条路径的偏差在容差以内，说明这次没有漏项或取值失误。若偏差过大，Agent 会停下来提示人工排查，而不是照样出价。

这一步的看点 · 三个容易被漏掉的行，Agent 都补上了废料回收（−20.53）：漏掉会让报价虚高，白丢单。校平工序（+10.80）：图纸有平面度要求就必须加，漏了要返工。前处理（含在表处 223.88 里）：喷涂前的脱脂磷化单独一档，最常被算成一笔。

这一步的看点 · 加急档「不多赚一分钱」看 B 档的加成率：和常规档一样是 28%，毛利率也一样是 21.9%。加急贵出来的 88 块钱全都是实际多花的成本—— 周末加班的双倍工资、喷涂线为了插单换色清线、物流多加一趟专车。Agent 没有借加急偷偷抬价。

这不只是道德问题，是谈判问题：客户问「凭什么贵 88 块」，销售能逐条把三项列出来。要是打包成「加急上浮 7%」，客户一问就答不上话。

C 档还触发了一个提醒：25% 加成率已经压到 A 类客户政策下限，Agent 标注了需销售经理审批—— 它知道什么价销售自己不能定。

批量档给销售准备的谈判话术

单价从 1,255 降到 1,147，看着是让了 8.6%。但 Agent 同时算出：量从 120 台到 300 台，这一单的毛利额从 3.30 万涨到 6.87 万。—— 让销售敢开口推批量档的，是后面这个数，不是前面那个。

但客户两天内就要回话，所以 Agent 给了不用等的办法 ——先发区间报价：
「按段焊 + 冷板口径：1,255 元/台；按满焊 + 镀锌板口径：1,390 元/台。最终价取决于这两项确认结果，确认后 2 小时内出正式价。」

同时自动生成两份东西：发技术的复核清单（只有那 2 项 A 级，附图纸位置和金额影响）、发客户的澄清函（A 级 2 项 + B 级 2 项，共 4 个问题）。
这一步的看点 · 也是整个 Demo 最想让你看到的地方Agent 完全可以给出一个漂亮的单价然后说「搞定了」—— 那样演示效果更好看。但它没有。

它算完了，然后告诉你这个价还不能发，并且说清了为什么（两项影响 1.27 万的口径没定）、以及不等技术怎么先回客户（区间报价）。

这就是 Agent 和「AI 随手估个价」的区别：它执行的是公司的规矩，不是尽快给个答案。对报价这件事来说，一个会在该停的地方停下来的助手，比一个永远给得出答案的助手可信得多 —— 因为按便宜口径报出去、按贵口径做进去，亏掉的是真金白银。
