二10 条可直接照做的任务

点「复制」拿走整段描述，粘进 WorkBuddy 即可

01

首推默认

这是康泰欣片一个品种最近六批的材料，都已随技能内置：01_月度产量与收率汇总表_本年度.xlsx、02_六批收率按时间排序与环比降幅.xlsx、03_收率数字逐批出处索引_含口径核对.xlsx、04_各批物料平衡页交叉核对.xlsx、05_去年11月同类下滑的处理记录.xlsx。 六批收率从 99.8 一路掉到 97.4，逐批都在 97–102% 内控限里，所以偏差流程一次都没触发过。我要知道把这六批连起来看是什么样子，以及去年 11 月那次同类下滑跟这次是不是一回事。 收率取自手写批记录，读不清或有涂改的标出来我去核对原始记录。分母口径不一致的批次单独列，别混进一条趋势里比。收率在掉的时候物料平衡是什么状态，要并排看。 产出三份 Excel：收率趋势体检表.xlsx 是正式件，含趋势主表、逐批出处索引、口径核对三个 sheet，带编制与审核签批栏；需人工确认清单.xlsx 一条一行，写明第几批第几页、要确认什么、找谁确认；排除项与依据清单.xlsx 写明排除了什么、依据是哪份记录的哪一栏。 偏差算不算重大、工艺要不要调，这两个结论留空，我自己判。

02

只做取数与口径核对

只跑取数和口径归一这两步，不用出趋势。读 03_收率数字逐批出处索引_含口径核对.xlsx，逐批核分母口径是理论片重还是投料量、扣没扣取样量。产出 Excel 一张口径核对表：批号、收率所在页、分母口径记载、是否扣除取样量、能否进趋势，末行给可确认批次数。

03

换成看距下限余量

把趋势口径换成「距内控下限还剩多少」，不用环比降幅。读 01_月度产量与收率汇总表_本年度.xlsx 与 02_六批收率按时间排序与环比降幅.xlsx。产出 Excel 一张余量表：批号、收率、距 97% 下限余量、按当前速率还剩几批触及下限，末行给结论。

04

两台压片机分开过

把 YP-01 与 YP-02 两台机各跑的 3 批分开拉一遍，看下滑是只出现在一台上还是两台都有。读 02_六批收率按时间排序与环比降幅.xlsx。产出 Excel 一张两机横向对照表：机台、所辖批次、各批收率、本机累计降幅、是否同向，按累计降幅排序，末行给能否排除设备。

05

给质量部讨论用的一页

把这份体检压成给质量部讨论偏差立项用的一页：读 02_六批收率按时间排序与环比降幅.xlsx 与 03_收率数字逐批出处索引_含口径核对.xlsx，只留连续六批降幅、累计 2.4 个点、末批距下限 0.4、口径待确认的 2 批。产出 Markdown 一页纸，每句带出处页码。

06

让它反驳自己

读 02_六批收率按时间排序与环比降幅.xlsx 与 04_各批物料平衡页交叉核对.xlsx，给这条趋势挑毛病：哪几批不该进趋势、哪几段环比降幅站不住、把设备因素排除掉的依据够不够。产出 Excel 一张复核表：结论项、支撑证据、留还是撤、理由与出处页码。

07

比对去年11月那次

读 05_去年11月同类下滑的处理记录.xlsx，把去年 11 月那次与这次逐项对一遍：连降几批、累计降多少、当时怎么处理、记录去了哪里、有没有进偏差或 CAPA 台账。产出 Excel 一张两次对照表，标出今年是更深还是更浅，以及当年那条处理记录没沉淀下来导致什么。

08

对照工艺卡片自查

读 01_月度产量与收率汇总表_本年度.xlsx 与 03_收率数字逐批出处索引_含口径核对.xlsx，对照现行工艺规程与车间在用的工艺卡片自查：内控限引的是哪一版、两版表述不一致的地方有没有标出来、每处数字有没有出处页码。产出 Excel 一张自查表：检查项、当前状态、依据文件、该补什么。

09

折算成原料损失与批次数

读 02_六批收率按时间排序与环比降幅.xlsx 与 01_月度产量与收率汇总表_本年度.xlsx，按六批合计投料 60.0 kg 与累计下滑 2.4 个百分点折算原料损失金额；再按末批距下限只剩 0.4 算还有几批会触及内控下限。产出 Excel 一张折算表：科目、算法、金额或批次数、依据出处。

10

沉淀成趋势体检清单

把这次用到的口径与核对动作整理成一张可复用的收率趋势体检清单：每批读哪几页、分母口径怎么核、口径不一致怎么标、趋势怎么算、谁签。产出 Markdown 一份，换个品种直接照抄。
