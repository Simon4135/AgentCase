Step 5 · 合规动作清单（🔴 重点人员）

证据链 + 法定流程 + 面谈话术 + 风险提示 · 红线人员单独处理
🔴 王大力 · 违纪解除（红线）
证据链：两次书面警告记录 + 车间监控录像 + 目击证人笔录
法定流程：书面通知 → 工会报备 → 协商解除 → 出具离职证明
面谈话术：「依据《员工手册》第 X 条，打架斗殴属严重违纪…公司决定解除劳动合同，补偿按 N 计算」
风险提示：证据链必须完整（警告+监控），避免仲裁败诉；确认无仲裁/诉讼在途
🔴 陈芳 · 绩效改进解除
证据链：连续两季度绩效 D 记录 + 出勤扣款记录
法定流程：PIP 面谈 → 30 天改进期 → 二次评估 → 解除
面谈话术：「按绩效改进计划约定，本季度目标未达成，公司将启动…」
风险提示：PIP 目标必须书面化、可量化；全程留痕；关注是否处于医疗期/孕产期

Step 7 · 典型追问 · Skill 怎么应对

追问 A · 为什么王大力直接淘汰，不给他改进机会？
王大力才 44 分，但他之前也干过活，能不能先警告观察？
Skill 应答：打架斗殴在《员工手册》里属于严重违纪（红线），制度层面就是直接解除的情形，不是绩效改进能覆盖的。Skill 已经把他标成红线一票否决，同时给出合规动作清单——证据链（两次警告+监控）齐全，流程走违纪解除而不是绩效解除，这样即使仲裁也有完整依据。给改进机会的前提是"绩效问题"，纪律问题不适用。
追问 B · 刘思远才 71 分，为什么还留他？
他绩效 C 又拿 28K，成本这么高为什么不直接优化掉？
Skill 应答：71 分确实落在 🟡 观察区，但直接动他的风险在于：他是高级开发工程师，核心研发岗，手上可能有项目在关键期——裁一个核心研发的成本（项目中断+再招聘+上手期）可能远高于他 28K 的月薪。所以 Skill 的建议是先 PIP 观察一个季度，同时评估薪资结构调整空间，如果改进期后仍不达标再走流程。这也是"高成本低绩效"识别背后的逻辑：不是见高成本就砍，而是给改进窗口、留证据、再决策。
追问 C · 名单给业务部门，他们不认怎么办？
业务经理说陈芳"其实挺努力的"，拒绝认可汰换名单。
Skill 应答：这正是口径固定的价值。可以跟业务经理说："陈芳连续两个季度绩效 D，综合分 57，四源数据都在表里——不是 HR 拍脑袋，是绩效系统、考勤系统、薪酬系统的客观数据。如果您觉得有特殊贡献可以补充，我们把它加进 PIP 改进期的评估依据，但数据口径不能变，否则下个季度名单又没法对齐。"用同一把尺子，名单就是共识。
