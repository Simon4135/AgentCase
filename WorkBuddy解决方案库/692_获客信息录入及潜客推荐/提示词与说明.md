*与一键体验入口一致*

```text
帮我导入手头的客户清单，并基于当前客户特征推荐相似的潜客，尽量获取到触达方式。
```

### 02　只做名单整理与核对

```text
先不做潜客推荐，只跑名单导入与核对：把名单里的公司逐家建档进 CRM、标记重复项与缺失项，每家写一条跟进记录。产出一张「导入结果清单」（Excel）：建档状态、重复判定、待补字段，逐家一行。
```

### 03　换画像口径再推荐

```text
把「相似潜客」的画像口径换成「同地区 + 相近产能规模」重跑推荐，其余条件不变。产出推荐名单对照表（Excel）：原口径与新口径各推荐了谁、理由有什么变化。
```

### 04　一次合并三份名单

```text
我手头还有名片扫描记录和渠道推荐两份名单，三份一起导入去重，合并成一张待筛选客户表。产出合并后的客户清单（Excel）：每条标注来自哪份名单、是否重复、置信度。
```

### 05　给销售总监的一页跟进清单

```text
把推荐结果压成一页给销售总监的「本周优先跟进清单」：每家潜客一句话由头、建议动作、公开联系方式、跟进人建议，按优先级排序。产出一页纸表格（Excel）。
```

### 06　让它反驳自己

```text
你刚推荐的相似潜客名单，逐家挑一个最可能站不住脚的理由（公开信号被误读、画像过度泛化、联系方式可能过期），逐条说明依据、要不要保留在名单里。产出疑点、依据、处置建议一张表（Excel）。
```

### 07　比对近一年赢单客户

```text
把这次的潜客推荐名单与 CRM 里近一年赢单客户的画像逐项比对，看「共同特征」是否真的成立；不成立的特征标记出来。产出比对表（Excel）：特征、赢单客户命中率、潜客命中率、是否成立的结论。
```

### 08　能力边界自查

```text
对照能力边界逐项自查这次的产出：有没有超出权限查 CRM、有没有把公开动态当成采购意向写、有没有编造联系方式；信息不足的项是不是都标了待核实。产出检查表（Excel）：检查项、是否通过、缺口。
```

### 09　折算成商机金额

```text
把 Top5 潜客按「预估产线规模 × 我方平均单产线成交额 × 商机概率」折算成预计 pipeline 金额，每个折算口径写明出处；产出折算明细表（Excel），并说明哪个口径最不确定。
```

### 10　沉淀成展会复盘模板

```text
把这次「名单导入 → 画像提炼 → 潜客推荐 → 触达补齐」用到的字段、判断口径和产出结构，沉淀成下次展会可直接套用的复盘模板。产出 Excel 模板（含字段说明），并列出哪些字段必须由人工确认。
```

### 一、这件事现在是什么样

*销售岗 · 展会获客 · 销售易·易启 Buddy 应用*

参加完一场展会后，销售收集了不少客户名单和现场沟通记录。接下来，既要整理这些信息也要判断哪些客户值得继续跟进。同时，销售还需要从手头的名单出发，找到更多值得接触的潜客。

### 二、痛点

*不是流程描述，是调研出来的真痛点*

1名单整理费时 — 客户信息整理需要手工识别、录入、补全和去重，耗费大量时间和精力。

2客户匹配度判断费力 — 只有公司名称和联系方式，销售还得继续查公司主营业务、近期动态，再结合产品分析潜在需求、寻找切入点，前期准备耗时较多。

3联系顺序靠感觉，精力容易分散 — 面对一长串名单，往往先联系信息齐全的、印象深的。真正匹配、有需求信号的客户可能排在后面；有些公司查了很久，才发现并不适合。

### 三、换个做法之后

*名单上传后，整理、画像、推荐一次做完 —— 数据放在哪就从哪读，不要求先建系统*

✕ 原来的做法
手工整理客户名单，统一格式、检查重复项，进行记录
凭经验总结客户特征，按行业继续找企业
结合资料搜集与经验判断，整理调查结果、标注相关信息，凭经验安排联系顺序

    ✓ 交给 Agent 之后
上传现有资料，Agent 提取企业信息、统一字段，确认后完成客户建档与跟进记录写入
Agent 结合产品介绍和名单中的业务信息，提炼客户共同画像，明确相似潜客条件
生成带建议优先级、依据和下一步动作的获客筛选表，供销售确认并安排跟进

### 四、场景闭环

*5 步 · 每一步的产出都是下一步的输入*

第 1 步
整理名单 · 把手头资料变成客户资产提取公司名称、联系人及联系方式，统一字段，标记重复与缺失项
第 2 步
调查企业 · 提炼共同画像梳理共同的业务场景、生产条件、需求问题与采购组织特点
第 3 步
判断潜客 · 从名单中拓展新机会依据画像寻找相似企业，结合扩产、新建产线、产品升级等公开信号
第 4 步
补齐信息 · 明确先找谁、从哪联系整理官网、公开总机、业务邮箱，给出联系优先级与待核实问题
第 5 步
确认承接 · 把推荐结果转为行动由销售确认优先级、补充修正关键信息，确定跟进人和联系计划

    要准备什么
展会收集到的公司名单表格
展区获取名单.xlsx · 公司名称 / 联系人 / 联系方式 / 现场记录

我方产品介绍与筛选要求
产品适用场景与目标客群口径，用于提炼共同画像

    沉淀价值

      不只整理好名单，更清楚客户底细、投入方向和下一步动作。

      · 一份统一的潜客清单：名片、展会名单、渠道推荐汇总去重，零散信息集中留存
      · 一套有依据的联系顺序：结合产品匹配度和需求信号，明确先跟谁、为什么值得优先投入
      · 一份具体的行动清单：哪些可以直接联系、哪些需要先调查、还缺什么信息，逐一明确
      · 一份可继续积累的客户资料：调查来源、筛选理由和待核实问题一并保留，下次跟进有据可查
