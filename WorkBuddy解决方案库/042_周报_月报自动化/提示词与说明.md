### 一、现状与痛点

周报是 Agency 客户策划岗最耗时的事之一，也是最容易掩盖问题的产出。一份"看似漂亮"的周报，可能藏着 6 个几乎每家 Agency 都会遇到的坑：

1数字堆砌，没有结论 GMV +6%、订单 +20%、UV +28%……每项都涨了，但客户看完不知道到底是好是坏，也不知道自己该做什么。

23-5 小时的重复劳动 拉数据、拼表格、算环比、做图表、写文案、导 PPT。一个策划一周有 3-5 小时都在做机械劳动。

3只报增长，不报隐忧 GMV 涨了但 AOV 降了、老客活跃在滑坡、试用装占比失控……表面数字掩盖了结构性问题，客户直到下个月才发现出事。

4洞察 = 复读机 "本周 GMV 环比上升" 这种翻译式描述不叫洞察。真洞察是"表面涨了但底层在劣化"，但没有时间深挖。

5行动项空泛无落地 "下周需要加强老客运营" —— 谁做？什么时候做？做什么？客户拿到周报没法直接分派。

6数据口径每周变一次 上周"新客"指 30 天内首购，这周变成 14 天内加入。客户没法看趋势，Agency 也没法追踪 KPI。

### 二、换个做法之后

WorkBuddy 把周报从"整理产出"变成"洞察产出"。策划只需要给几张最简单的 CSV，AI 就能自动完成：数据聚合 → 环比归因 → 洞察挖掘 → 行动清单 → 可直接给客户看的 PPT/HTML。

  ❌ 传统做法

    策划从 3 个后台各导一份 Excel → 拼表 → 手工算环比 → 做图 → 写洞察 → 导 PPT。3-5 小时 · 每次都要重来。数据口径靠人记忆维护。

  ✅ WorkBuddy

    丢 3 张固定格式的 CSV 进去 → 3 分钟出完整周报 · 含 5 条深度洞察 + 6 条带优先级的行动清单。数据口径固化在配置里，永远一致。

三个核心价值

核心价值 · 一
释放策划的深度思考时间
把 3-5 小时的机械劳动压缩到 3 分钟，剩下的时间用来做真正有价值的策略推演，而不是拼表格。

核心价值 · 二
主动挖出"表面正常"下的隐忧
AI 会自动做多维度交叉分析，比如"总盘涨但 AOV 跌 + 老客活跃降"这种人工需要盯着看半小时才能发现的隐性问题，直接抛出来。

核心价值 · 三
让每份周报都能过挑剔客户的挑战
每条洞察带数据支撑、每条行动带负责人和截止时间。品牌方 CMO 一看就知道"这份周报能直接分派下去"，这是策划专业度的直接证明。

### 三、场景闭环

整个流程完全自动，策划只需要在最后做业务上的确认与措辞微调：

  Step 1
导入 3 张 CSV每日 KPI + 品类拆分 + 本周事件。所有后台都能一键导出。

  Step 2
自动聚合 + 归因环比同比 · 多维交叉 · 事件与指标关联 · 找结构性变化。

  Step 3
生成洞察 + 行动✅亮点 / ⚠️下滑 / 🔍 深度洞察 · 每条带数据支撑与执行方案。

  Step 4
导出多格式HTML 可视化 + PPT + 微信长图 + Markdown · 客户想要什么给什么。

(function(){
  if(window.self === window.top) return;
  document.addEventListener('click', function(e){
    var a = e.target.closest ? e.target.closest('a[href]') : null;
    if(!a || a.target === '_blank') return;
    var u;
    try { u = new URL(a.getAttribute('href'), location.href); } catch(err){ return; }
    if(u.origin !== location.origin || !/\.html?$/i.test(u.pathname)) return;
    e.preventDefault();
    window.parent.postMessage({type:'wb-subnav', url:u.href}, '*');
  });
})();
