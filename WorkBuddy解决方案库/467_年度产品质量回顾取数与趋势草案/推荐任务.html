二10 条可直接照做的任务

点「复制」拿走整段描述，粘进 WorkBuddy 即可

01

首推默认

该做本品种的年度质量回顾了，全年 23 个批次。材料已随技能内置：01_六块数据取数状态与出处索引.xlsx、02_APR工时结构与本次收口范围.xlsx、03_全年四类趋势汇总.xlsx、04_三类边缘项与历年结论段对比.xlsx。 数据分散在批记录、偏差台账、CAPA 台账、投诉记录、稳定性数据、供应商审计六处，格式不一样。帮我把取数和核对这部分做掉，每个数字标出处，取不到的列成缺口别猜。口径如果年中变过，分段说明，别混在一条趋势里比。 结论和改进建议留空，我自己写——这部分工时不要动。另外把「在限内但趋势异常」「关闭但无有效性证据」「跨年重复出现」这类需要人判断的项单独标出来。 产出三份 Excel：年度产品质量回顾草案.xlsx 是正式件，含批次汇总、偏差与CAPA、投诉、稳定性、供应商、趋势图表六个 sheet，结论与改进建议留空，每页标注「草案，须与原始批记录核对后方可签署」；需判断项清单.xlsx 把三类边缘项逐条列出，写明为什么需要人判断、依据在哪；取数缺口与出处索引.xlsx 写明每个数字的来源文件与页码，取不到的写明找谁要。

02

只盘取数缺口

只跑取数这一步，先不做趋势。读 01_六块数据取数状态与出处索引.xlsx。产出 Excel 一张取数表：数据块、在谁手上、载体形态、应取项、实取项、完整性、缺什么，末行给完整与不完整各几块。

03

把 CAPA 关闭口径收紧

这次把 CAPA「关闭」的口径换成「须含有效性验证证据」，此前只要填了关闭日期就算关。读 01_六块数据取数状态与出处索引.xlsx 与 03_全年四类趋势汇总.xlsx。产出 Excel 一张两口径对照表：CAPA 编号、原口径是否关闭、收紧后是否成立、缺什么证据，关闭率的变化要算出来。

04

四类趋势一起过

把收率、偏差、CAPA、投诉四类趋势一次全过。读 03_全年四类趋势汇总.xlsx。产出 Excel 一张四类横向对照表：趋势类别、全年情况、关键发现、是否需人判断、依据出处，按是否需人判断排序，末行给需判断与可排除各几类。

05

给受权人会签前的一页

读 01_六块数据取数状态与出处索引.xlsx 与 03_全年四类趋势汇总.xlsx，把草案压成受权人会签前看的一页：六块数据哪几块完整、哪两块缺什么、三类边缘项各几条、哪几项跨年重复出现。产出 Markdown 一页纸，每项带依据出处。

06

让它反驳自己

读 03_全年四类趋势汇总.xlsx 与 04_三类边缘项与历年结论段对比.xlsx，给「投诉趋势可以排除为本年度重点」这条、还有那 3 条「关闭但无有效性证据」的 CAPA 挑毛病。产出 Excel 一张复核表：结论项、支撑证据、留还是撤、理由与出处，站不住的就改成待核。

07

比对历年结论段

读 04_三类边缘项与历年结论段对比.xlsx，把今年与去年、前年的 APR 结论段并列，再看今年的边缘项里哪几条是跨年重复出现的。产出 Excel 一张历年对照表：结论段原文出自哪一年、跨年重复的边缘项、上次提出过什么措施、有没有 CAPA 跟进。

08

对照必备章节自查

读 01_六块数据取数状态与出处索引.xlsx 与 03_全年四类趋势汇总.xlsx，对照年度回顾的必备章节自查：六个载体齐不齐、收率分母全年是不是同一把尺子、每个数字有没有出处、缺的章节有没有写明找谁要。产出 Excel 一张自查表：必备章节、本次情况、依据、缺什么。

09

折算成停售量级的影响面

那 3 条「关闭但无有效性证据」的 CAPA 与连续 6 批下滑的收率趋势，如果一直不处理，按同类企业被暂停产销的处置量级折算影响面。读 03 与 04 两份材料。产出 Excel 一张影响表：风险项、可能后果、涉及批次与产量、依据出处、算法。

10

沉淀成 APR 取数模板

读 01_六块数据取数状态与出处索引.xlsx 与 02_APR工时结构与本次收口范围.xlsx，把取数口径整理成一份可复用的 APR 取数模板：六个载体各取哪几栏、出处怎么标、口径怎么核、边缘项怎么判、谁签。产出 Markdown 一份，明年照抄。
