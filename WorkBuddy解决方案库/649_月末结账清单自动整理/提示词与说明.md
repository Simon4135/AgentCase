### 一、这件事现在是什么样

*财务专员 · 每月关账前与清单赛跑的一周*

某连锁餐饮企业，月末最后两天。财务专员的桌上摊着四个主体的结账事项：总部 HO001、深圳区域、南山店、福田店 —— 凭证审没审完在微信里，折旧提没提在折旧摊销表里，对账差异在对账表里，税表还是草稿。哪个主体进度过半、哪个还卡着，得翻四五个文件加十几条聊天记录才能拼出来。最怕的是关账前一夜：总部试算差 1,256.78 元，借贷不平 —— 这种异常关账时点强约束下就是返工，查不出来谁都不敢点「关账」。清单靠脑子记，进度靠嘴问，遗漏一项，下月第一件事就是挨问。

### 二、痛点 · 每个月结都在重演

*不是流程描述，是财务每月真实经历的消耗 —— 以下内容取自场景调研*

1结账事项跨多模块易遗漏：凭证、资产、税务、对账、关账五大类各有若干任务，漏提一笔折旧、漏算一个附加税，关账后才发现就是差错

2多主体进度分散难跟踪：总部、区域、门店各自的完成度散在不同文件和聊天记录里，「现在到底还差几项」没人能一句话答上来

3关账时点强约束返工成本高：关账截止就在眼前，发现试算不平衡时已经没有从容排查的时间，返工都在深夜

4异常发现晚：试算差异 1,256.78 元这种阻断级问题，往往是关账前最后一刻才撞见 —— 早发现一天和晚发现一天，是两个周末

### 三、换个做法之后

*变化不在「快」，在「不漏」和「敢关账」*

✕ 现在的做法
五大类结账事项靠脑子记、靠旧清单抄，漏一项算一项
多主体进度翻文件翻聊天记录拼，永远说不清整体完成率
试算不平衡等阻断级异常关账前夜才撞见，深夜返工
遗漏项、逾期项没有预警，靠人盯人

    ✓ 交给 Agent 之后
按凭证/资产/税务/对账/关账五大类模板化生成任务清单，含前置依赖关系
逐主体逐任务标记状态，完成率自动算，遗漏项与即将逾期项自动标
关账前置自动校验：试算平衡/损益结转/折旧摊销/对账差异，异常项直接阻断关账建议
清单报告 + CSV 明细 + HTML 进度看板一次给齐，10 分钟拿到

### 四、场景闭环

*6 步 · 解析 → 归集 → 汇总 → 校验 → 交付*

第 1 步
周期与主体识别 · 先定骨架解析结账周期（年月）+ 核算主体清单；无主体清单时按总部 + 区域 + 门店三层生成默认骨架
第 2 步
多源文件解析 · 各归其类解析科目余额表 / 折旧摊销表 / 对账差异表 / 税表草稿（Excel/CSV，多文件多 Sheet），按文件类型匹配结账类别
第 3 步
五大类任务归集 · 模板化生成按凭证 / 资产 / 税务 / 对账 / 关账五大类模板化生成结账任务项，含标准任务清单与前置依赖关系图
第 4 步
进度汇总 · 完成率自动算逐主体逐任务标记完成状态，自动计算各主体完成率与整体完成率，标记遗漏项与即将逾期项
第 5 步
关账前置校验 · 异常直接阻断自动校验试算平衡 / 损益结转 / 折旧计提 / 摊销计提 / 对账差异，异常项阻断关账建议
第 6 步
结构化输出 · 可追溯交付结账清单 Markdown 报告 + CSV 明细（UTF-8 BOM）+ HTML 进度看板，任务项附模板编号或文件行号

    要准备什么
结账周期（年月）+ 核算主体清单（可选）
无主体清单时按总部+区域+门店三层默认骨架生成

科目余额表 / 折旧摊销表 / 对账差异表 / 税表草稿
Excel/CSV 原样扔进来 —— 多文件多 Sheet 均可

已完成的结账进度（如有）
口头说清或文字粘贴均可 —— 缺项按未完成计

    为什么这个场景值得做

      痛感 4 × AI 适配 4 ÷ 落地难度 2 = 8.0

      最大差异点 · 不动 ERP、不改结账流程：散落的四类财务文件原样扔进来，清单、进度、前置校验一次成型 —— 财务只做异常项复核与关账拍板。

      评分口径：痛感看「这事没做好谁会生气、生气到什么程度」；
      AI 适配看「输入是否非结构化、是否要跨渠道取数、错了能不能当场看出来」；
      落地难度是分母 —— 需要先对接 POS/ERP 才能用的场景，分数会被压得很低。

  这套东西不承诺什么
不替代真实 ERP 结账操作；不直接调用财务系统 API；不生成会计凭证；不对接银企直联与税务申报接口。试算平衡校验仅校验借贷合计是否相等（容差 0.01 元），无法识别科目串户或方向性错误，财务主管须逐科目复核余额合理性；默认五大类任务模板基于通用餐饮连锁场景，加盟、中央厨房、预制菜等特殊业务可能存在未覆盖事项，须结合企业实际增补；本 Skill 仅输出关账建议与阻断预警，禁止自动关账 —— 关账决策须财务主管最终确认。
