二痛点

1
MRP 算得出缺口，答不出怎么办 — 系统报"M-SPCC-20 缺 532 kg、M-PCB-001 缺 60 pcs"，接下来全靠人：能不能用替代料？库里那批呆滞板材规格接近能不能顶？要不要花钱买现货？这些判断需要图纸公差、客户 PPAP 约束、呆滞料实测值、供应商 MOQ 四类信息，而它们分散在图纸、PPAP 文件、库龄表、供应商邮件里，一样都不在 ERP 的计算范围内。
2
库存看着够，开工才发现动不了 — M-PCB-001 总库存 320 pcs，MRP 里显示不缺。但扣掉安全库存 80、被其他在制工单分配的 100、IQC 未放行的待检 20，真正可用只有 120 pcs。很多企业的齐套报表直接拿总库存算，算出"齐套"，结果开线当天才发现料动不了。
3
技术上能替，客户不认也白搭 — M-PCB-002 与 M-PCB-001 是 Pin-to-Pin 兼容，做过 1000h 老化和 EMC 复测，技术结论完全等效。但某主机厂的 PPAP 已锁定料号 M-PCB-001，要换就得重走 PPAP Level 3 含PSW 重签，周期 4-6 周。同一颗替代料，华东电气可以用、某主机厂不能用——这道商务门槛比技术门槛更硬，但 ERP 里没有这个字段。

三换个做法之后

先把口径算准，再按漏斗顺序过六条路径，每条给可行性 + 代价 + 风险 + 前置条件，最后落到三色结论和责任人。

传统做法

  • MRP 出缺口清单 → 采购凭经验想办法 → 问工艺能不能替、问仓库有没有类似料、问供应商能不能催→ 各方口头答复散在微信里 → 最后拍一个方案。
  • 替代料被客户否决、呆滞料能用却没想到、为伪缺口付了溢价，都是常见结果。

WorkBuddy

  • 七份数据一次读完 → 可用库存按四项扣减算准 → 六条路径按漏斗顺序逐条判定（先用已有资源、再用时间腾挪、最后才花钱或动客户）→ 532 kg 与 60 pcs 缺口全部化解且收敛验算为 0 → 6 张工单三色结论（绿 2 / 黄 3 / 红 1），每张写清缺什么、走哪条路、谁在什么时点做完什么。

核心价值

路径有先后不是并列

替代料/呆滞料不花钱不延期，必须先试；分批投产只换口径不消耗物料；紧急采购花钱；调整交期动客户代价最高。顺序错了就会为伪缺口付溢价。

替代料四道校验

客户认可 / 技术等效 / 是否需重新首件 / 成本差异，缺一道即不可用。且第一道是硬门槛——技术全过，PPAP 锁料号照样出局。
